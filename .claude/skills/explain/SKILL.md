# Explain

Explain the given code, file, concept or command to Chris (Junior Fullstack Developer).

## How to explain
- Language: German. Keep technical terms in English (e.g. "Props", "Hook", "State") and explain them once.
- Start with one or two sentences: what does it do and why does it exist?
- Then go through the code step by step, in small chunks, quoting the relevant lines.
- Focus on the "why": why this approach, what problem it solves, what would go wrong without it.
- Use a short, simple example or comparison when a concept is abstract.
- Depth:
  - HTML/CSS/Tailwind: brief
  - JS/TS/React: detailed
- Point out common beginner mistakes related to the topic, if relevant.

## End with
- A short summary (2–3 bullet points)
- Optionally one link to the official docs (React, MDN, TypeScript, Tailwind, Vite)
- Ask if anything is still unclear

## Rules
- Do not change any files.
- Do not invent APIs – if unsure, check the official docs first.
